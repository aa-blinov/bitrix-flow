# Скриншоты

Снимки для [README.md](../../README.md). Все сделаны на фиксированном наборе данных
UI-тестов (`MOCK_B24=1`), не на боевом портале.

| Файл                   | Что на нём                                                  |
| ---------------------- | ----------------------------------------------------------- |
| `home.png`             | Главная: просроченные задачи, задачи без дедлайна, проекты. |
| `kanban.png`           | Доска проекта: канбан, стадии, план и факт часов.           |
| `task-modal.png`       | Карточка задачи поверх доски.                               |
| `workload.png`         | Нагрузка команды: недельный календарь по исполнителям.      |
| `projects-summary.png` | Сводка проектов: план и факт часов, статус, период.         |
| `notifications.png`    | Лента уведомлений с фильтрами.                              |
| `search.png`           | Поиск по всем проектам.                                     |

Переснять снимки: `npm run screenshots`. Скрипт собирает приложение и снимает экраны в
том же образе Playwright, что и CI.
