# Design System: BitrixFlow

## Overview

Оформление BitrixFlow — это набор [@monos/ui](https://github.com/aa-blinov/monos-ui).
Палитры, токены, типографика и правила живут в наборе; приложение берёт их
пакетом, а не переписывает своими.

Что это значит на практике:

- Значения цветов, отступов и радиусов не придуманы здесь. В приложении есть
  только **роли** (`bg-surface`, `text-ink-soft`, `border-line`), а значения за
  ними живут в пакете.
- Смена палитры и режима — это смена атрибутов на `<html>`, а не перезаливка
  стилей в компонентах.
- Новый экран собирается из примитивов набора (`src/components/monos/`), а не из
  новых велосипедов.

Набор написан на Svelte, а приложение — на React 19, поэтому примитивы
перенесены вручную: разметка, классы и поведение повторяют исходник один в
один. Правила переноса и таблица замен классов — в
[docs/monos-ui-porting.md](docs/monos-ui-porting.md).

## Как это подключено

| Слой             | Источник                                        |
| ---------------- | ----------------------------------------------- |
| Токены и палитры | `@monos/ui/styles.css` (пакет из GitHub)        |
| Имена в Tailwind | мост `@theme inline` в `src/app/globals.css`    |
| Примитивы        | `src/components/monos/*` (перенесены из набора) |
| Палитра и режим  | `data-theme` + `data-mode` на `<html>`          |

Пресет набора рассчитан на Tailwind 3, а приложение живёт на Tailwind 4, где
тема описывается прямо в CSS. Поэтому те же имена перечислены ещё раз в
`@theme inline`: `inline` означает, что утилита подставляет `var(--ui-…)`
прямо в правило, и тема переключается на лету, без пересборки.

## Палитры и режимы

Шесть палитр, каждая в светлом и тёмном режиме:

| Палитра      | Светлая        | Тёмная        |
| ------------ | -------------- | ------------- |
| `gruvbox`    | тёплый серый   | тёплый уголь  |
| `github`     | белый          | тёмный        |
| `dracula`    | светлый фиолет | тёмный фиолет |
| `nord`       | холодный       | сине-серый    |
| `solarized`  | песочный       | тёмный        |
| `catppuccin` | розовый        | тёмный        |

По умолчанию — `gruvbox`, режим берётся из системной настройки. Выбор
хранится в `localStorage` по ключу `bitrix-flow-theme` в формате
`палитра:режим` и переживает перезагрузку.

### Контраст

В части палитр приглушённые роли набора не дотягивают до WCAG AA: в грувбоксе
`ink-soft` на приподнятой поверхности даёт 3.65:1, а требование — 4.5:1.
Значения таких ролей переопределены в `src/app/globals.css` по каждой палитре и
режиму: сдвиг к чёрному в светлой теме и к белому в тёмной. Характер палитр
сохраняется, меняется только читаемость. Проверяет это `npm run check:contrast`
(все 12 сочетаний), а интерфейс целиком — axe-core в UI-тестах.

## Colors

Цвет в наборе — это **состояние**, а не украшение. Роли:

| Роль                                      | Смысл                                    |
| ----------------------------------------- | ---------------------------------------- |
| `canvas`                                  | фон страницы                             |
| `surface`                                 | карточка, панель, поле                   |
| `surface-2`                               | приподнятое: марк проекта, код, подложка |
| `ink`                                     | основной текст                           |
| `ink-soft`                                | вторичный текст                          |
| `ink-faint`                               | метаданные, подписи                      |
| `ink-muted`                               | неактивное и разделительное              |
| `line` / `line-strong`                    | границы, границы выбранного              |
| `accent`                                  | единственный акцент палитры              |
| `danger` / `warning` / `success` / `info` | сигналы                                  |
| `*-text`                                  | читаемые варианты сигналов на своём фоне |

### Named Rules

- Цвет говорит о состоянии, а не о бренде. Проект помечается инициалами на
  `surface-2`, а не радугой оттенков.
- Красный — только «не готово» (просрочено, ошибка, удаление).
- Приоритет задачи — тоже состояние: высокий и критический тянут на тёплые
  роли, обычный остаётся тихим.

## Typography

Одна гарнитура на всё приложение: **JetBrains Mono** с системным
моноширинным запасным. Подгружается через `next/font` с кириллицей.

| Роль      | Размер | Где                                    |
| --------- | ------ | -------------------------------------- |
| Заголовок | 20px   | заголовок страницы                     |
| Интерфейс | 14px   | основной текст                         |
| Метка     | 12px   | подписи полей, вторичный текст         |
| Шёпот     | 11px   | метаданные, верхний регистр + разрядка |

### Named Rules

- Заголовки и метки — с разрядкой, шёпот всегда капсом.
- Цифры в таблицах — `tabular-nums`, иначе колонка прыгает при обновлении.

## Layout

Шкала отступов набора: `hair` 2px, `tight` 4px, `field` 6px, `snug` 8px,
`input` 10px, `base` 12px, `comfortable` 16px, `roomy` 24px, `section` 32px.

## Elevation & Depth

- `shadow-rest` — поверхность в покое.
- `shadow-lift` — приподнятая поверхность (карточка под курсором).
- `shadow-overlay` — окно, меню, подсказка.

## Shapes

Один радиус — `rounded-ui`, 6px. Круглым остаётся только круг: аватар,
точка статуса, круглый счётчик.

## Controls

Высота контрола: 28px (`sm`), 32px (`md`), 36px (`lg`), 44px (`touch`).
На телефоне любой интерактивный элемент — не меньше 44px.

| --------------------------------------------------------------- | ----------------------------------- |

| `TextField`, `TextArea`, `SelectField`                          | `Input`, `Textarea`, `Select`       |
| `Checkbox`, `Switch`, `RadioGroup`                              | `Checkbox`                          |

### Buttons

Кнопка в наборе — это слово. Залитой кнопки нет: главное действие выглядит
как жирное слово, второстепенное — как обычное. Обводка принадлежит выбору из
вариантов, а не действию.

### Badges

Слово-статус: капс, разрядка, тихий цвет. Точка рядом — когда статус важно
заметить в мелком кегле.

### Kanban column

Колонка — `surface-2`, карточка задачи — `surface` с тонкой линией. Карточка
приподнимается под курсором и показывает состояние цветом точки стадии.

### Kanban card (signature)

Плотная строка без лишней рамки: название, метаданные капсом, исполнитель и
срок. Цвет точки стадии дублируется подписью — по одному цвету состояние не
читается.

### Inputs / Fields

Поле — либо строка формы (`underline`), либо отдельный предмет (`boxed`).
Подпись капсом сверху, подсказка снизу, ошибка вместо подсказки.

### Navigation

Строка навигации — 36px, активная помечена фоном и `aria-current="page"`.
Разделитель — волосок, не линия в два пикселя.

## Do's and Don'ts

### Do:

- брать цвет из ролей (`bg-surface`, `text-ink-soft`), а не из палитры Tailwind;
- собирать новый экран из примитивов `src/components/monos/`;
- держать 44px для пальца на телефоне;
- подписывать состояние текстом рядом с цветом;
- брать радиус `rounded-ui` и не выдумывать новый.

### Don't:

- не заливать кнопки и не обводить их: слово вместо этого;
- не использовать `dark:`-варианты: тёмный режим задаёт палитра;
- не брать сырой цвет (`#fff`, `text-slate-500`) — только роль;
- не тащить в проект компоненты из `shadcn/ui`: набор их заменил;
- не раздувать интерфейс: одна линия, один радиус, одна гарнитура.
